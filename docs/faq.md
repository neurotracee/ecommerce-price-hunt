# FAQ

### 这是什么项目？和 DSH go 什么关系？

这是为 [DSH go](https://github.com/ccch1mneyyy/dsh-go/) 做的**附属功能**开源项目，把「AI 自动全网比价」沉淀成一份可复用的 Skill。它不是官方组件、不含上游代码、独立授权，也不代表上游立场。详见 `NOTICE.md`。

### 最省事的安装方式是什么？

三步，不用 clone、不用敲命令、不用在页面里翻上翻下：

1. 直接把 Release 里的 `ecommerce-price-hunt-vX.Y.Z.zip` 下载下来（GitHub 与 Gitee 都有）。
2. 把**下载到的 zip 文件本身**直接发给 DSH：拖进对话框或作为附件上传。**不要把下载链接发给 AI，也不要让它跳转去下载**——链接不一定打得开，来回跳转和重试只会白白消耗时间与 token。给文件，不给链接。
3. 对它说：

   > 帮我安装它到本地目录即可，我要把它添加进来。

DSH 会自己解压并放进本地技能目录，装完回报路径。手动 `cp -r` 只用于换到其它 Agent 宿主。

### 能不能自动抓价格 / 有没有 API / 能不能批量跑？

不能，也不打算做。仓库里只有提示词与操作手册，靠 Agent 的读屏能力以人工节奏浏览。批量爬取、高频轮询、协议逆向、绕过风控都在禁止清单里。

### 为什么结果要出 HTML 报告，不直接在对话里给结论？

比价结果涉及多平台、多规格、单价换算、券门槛和发货时效，对话里很容易丢字段或前后口径不一致。固定章节 + 全量清单 + 数据说明与局限，便于核对，也便于下次复用。最终对话回复仍要求 ≤300 字、≤8 行只讲结论。

### 为什么药品要单独一套规则？

因为「名字像药」的商品里混有妆字号、消字号、保健食品和洗护用品，混表会给出错误甚至有风险的建议。闸门是国药准字 + OTC/RX + 剂型通用名三者齐全；查不到文号写「未核实」。**结果仅供个人参考，不得用于药品广告、价格宣传、诊疗建议或对外比价榜单；用药请遵医嘱或药师指导。**

### 可以商用吗？

**可以。** 文档与提示词是 **CC BY-SA 4.0**（允许商用，但必须署名、标注 GitHub 与 Gitee 两个仓库地址并说明由同一作者管理、注明是否修改，衍生文档须同协议共享）；代码/模板是 **MIT**。不需要付费、不需要申请、不需要等作者批准。

需要注意：**协议 ≠ 用途**。「允许商用」放开的是版权层面的使用方式；`SKILL.md` 的用途限制依然有效——不得群控/刷单/抢购/批量爬取/抓取个人信息，比价结果不得用于药品广告、价格宣传、诊疗建议或对外发布的比价榜单。具体合规请咨询律师。

### 支持哪些平台？

手册记录了 2026-11 实测的六个：京东、拼多多、淘宝（网页版）、抖音商城、快手商城、美团买药。平台改版很快，欢迎按 `CONTRIBUTING.md` 补充实录。

### 报告里的价格准不准？

只记录使用者本人当下实时读到的数字，并带采集时间与活动条件。价格随大促按小时变化，作者不保证时效性，也不对据此产生的损失负责。示例文件里的数字全部是虚构占位。

### 读不到屏幕 / 页面是图怎么办？

先按 `references/screen-reading.md` 的快路走：优先读无障碍树，只有图时截图读数；筛选面板常是可读的原生面板；详情页继续滚，仍查不到就进结算页看规格与实付（**不提交订单**）。实在读不到就写进「局限」，不猜。

### 遇到登录、验证码、应用锁、支付怎么办？

立即交还用户，不绕过、不反复触发。结算页只看到价格为止，不提交订单。

### Release 里有什么？

一个可直接放进技能目录的 zip（含 `SKILL.md`、`references/`、`assets/` 与项目文档），以及重复了完整免责声明与 DSH go 出处的发布说明。GitHub 与 Gitee 镜像同步发布。

### 我改了 `SKILL.md`，怎么确认没弄坏结构？

`python scripts/validate.py`。它检查 frontmatter、按需加载表引用的文件是否存在、免责声明是否保留、HTML 骨架是否标注虚构数据。

### 想加一个新平台的坑位，怎么提？

开 Issue 说明现象与对策，PR 只改 `references/platform-playbooks.md` 相关行；不要带真实品牌/价格/店铺名，也不要贴含个人信息的截图。
