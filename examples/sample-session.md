# 一次任务的流程示例（全虚构）

> 本文演示**流程与产物结构**，不演示真实比价结果。所有平台、店铺、价格、日期均为占位；`¥0.00`、`0.000` 表示「此处应填使用者本人实时读到的数字」。请勿把示例数字当成报价。

## 用户输入

> 开始针对「〈某品牌 某商品 100g〉」做全网比价，出 HTML 报告，我收货地在〈某省某市〉。只看前 3 名深挖。

## Agent 的执行轨迹（应然，不是实录）

1. **第 0 步 · 品类判定**：无药/妆/食/健/械字号 → 普通商品，走通用规则。药品专项不启用。
2. **应用清单**：确认本机有哪些综合电商 App；发现〈某外卖 App〉只有本地即时零售，不作为综合电商计入，并在报告说明。
3. **按需加载**：首次做〈平台 A〉→ 读 `references/platform-playbooks.md`；遇到图片渲染页 → 读 `references/screen-reading.md`；换算时 → 读 `references/pricing-method.md`；写报告前 → 读 `references/report-spec.md` + 随包的 `vendor/answer-visualization-preference/SKILL.md` 与 `vendor/html-visualization/html/SKILL.md`。
4. **逐平台采集**（每个平台）：
   - 搜「品牌 + 商品名」→ 切「商品」页签；
   - 价格低→高排序记前三，销量排序记前三；
   - 打开筛选面板看大促/补贴/券后/价保/包邮/发货地标签；
   - 每平台至少滚 3–5 屏，多进几家店；
   - 详情页继续往下滚核对规格；读不到就点「立即购买」进结算页看款式、运费、实付，**不提交订单**；
   - 记销量/付款人数，低价但个位数付款的标风险。
5. **落地表**（先落表，再写报告）：

   ```
   平台 | 店铺 | 商品名 | 规格 | 标价 | 实付 | 单价(元/g) | 销量 | 标签 | 采集时间
   〈平台 A〉 | 〈店铺占位〉 | 〈商品占位〉 | 100g | ¥0.00 | ¥0.00 | 0.000 | 〈数字占位〉 | 包邮/券后 | 〈时间〉
   〈平台 B〉 | 〈店铺占位〉 | 〈商品占位〉 | 100g | ¥0.00 | ¥0.00 | 0.000 | 〈数字占位〉 | 满减/运费 | 〈时间〉
   ```

   缺字段留空并在「局限」里说明，**不猜**。

6. **前 3 名深挖**：发货地、默认快递、发货承诺、到货预估（按用户城市）；能问客服就问并保留原话；页面「预计 N 天」与客服「3–5 天」分开记。其余链接只进全量清单。
7. **交付 HTML**：按 `references/report-spec.md` 的 10 章节生成单文件报告；**先探测本机（或按机型查资料）拿到手机与桌面的真实视口**，在这两档各跑一次自检，横向溢出为 0；报告里写清采集时间、活动条件、口径、**自检用的两个视口及其来源**与局限。
8. **最终回复**：≤300 字、≤8 行，只说结论和该看报告哪一节。

## 报告章节（示意）

1. 结论 hero（最低单价大数字 + 3 要点）
2. 指标条（采集条数 / 单价区间 / 最高最低倍数）
3. 每平台最低价横向条形图
4. 同平台价差区间
5. 最低价前 3 名（实付 / 发货地 / 时效）
6. 全量清单（单价升序：平台 / 店铺 / 到手价 / 单价 / 销量 / 标签）
7. 平台活动标签卡
8. 三种买法（最便宜 / 最稳 / 要发票或售后）
9. 坑（品牌错标、低价少销量、多盒折算、券后门槛等）
10. 数据说明与局限

## 交付检查（逐条打勾）

- [ ] 每条记录能对上「平台 + 店铺 + 规格 + 价格 + 时间」
- [ ] 品类判定与排除项写清（药品任务还要报剔除数量）
- [ ] 实付含运费，券门槛写明
- [ ] 前 3 名都有发货地 / 快递 / 时效与客服原话（没有则写明「未公示 / 无法在线咨询」）
- [ ] 双屏截图自检通过、无横向溢出
- [ ] 局限如实（读不到、无客服、发货地未公示、只能网页版）
- [ ] 示例数字全部标注为占位/虚构，推断与实测分开写

## 如果中途遇到障碍

| 现象 | 正确做法 |
| --- | --- |
| 弹出登录 / 验证码 / 应用锁 | 停止并交还用户，不绕过 |
| 详情页只有图、读不到规格 | 截图读数 → 继续滚 → 结算页看款式 → 仍读不到就写「未核实」 |
| 网页版提示「仅支持客户端购买」 | 报告写明「只能网页版、无 App 客服」 |
| 平台只有 2–3 条链接 | 如实说明，不拿别的平台数据补 |
